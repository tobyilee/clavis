단어로 찾는 전문 검색과, 뜻으로 찾는 의미 검색입니다. 상위 문서: [[Clavis 사용 매뉴얼]]

## 빠른 검색 (⌘K)

- 헤더의 검색 칸을 누르거나 **⌘K**(Windows는 Ctrl+K)를 누르면 검색 팔레트가 열립니다.
- 페이지 이름이나 내용을 입력하면 바로 결과가 나오고, 고르면 그 페이지로 갑니다.
- 맨 아래의 **"…" 전체 검색**을 누르면 검색 화면으로 갑니다.

## 검색 화면

- 필터: **Space**, **유형**, **상태**
- 결과마다 제목, 유형·상태, Space, 마지막 수정 시각, 찾은 부분(강조 표시)이 나옵니다.
- **더 보기**로 다음 결과를 불러옵니다.

### 단어 검색의 특징

- 검색어가 여러 개면 **모두** 들어간 문서만 찾습니다.
- **3글자 이상**은 색인으로 빠르게, 더 짧은 검색어는 부분 일치로 찾습니다.
- 띄어쓰기가 다르면 찾지 못합니다 (`부분 환불` ≠ `부분환불`). 이럴 때 **뜻으로 찾기**를 켜세요.

## 뜻으로 찾기 (의미 검색)

검색 화면의 **뜻으로 찾기**를 켜면, 단어가 달라도 뜻이 비슷한 내용을 함께 찾습니다.

- 예: "환불 기준" → "부분 취소 정책", "배포는 누가 승인하나" → "릴리스 절차" 섹션
- 질문 문장으로 써도 됩니다.
- 단어 검색 결과와 뜻으로 찾은 결과를 **합쳐서** 순서를 매깁니다. 두 쪽 모두에서 찾은 문서가 위로 올라옵니다.
- 결과에는 가장 가까운 **섹션**이 "› 섹션 이름"으로 붙고, 누르면 그 섹션으로 바로 갑니다.
- 결과는 한 페이지(최대 20개)만 나옵니다 (**더 보기** 없음).
- 일시적으로 쓸 수 없으면 "뜻으로 찾기를 지금 쓸 수 없어 글자로 찾은 결과입니다"라는 안내와 함께 단어 검색 결과가 나옵니다.

### 의미 검색이 문서를 읽는 방식

- 문서는 **H2 섹션 단위**로 나뉘어 색인됩니다. 첫 H2 앞의 도입부도 따로 하나이고, 2,000자가 넘는 섹션은 나뉩니다. H3 이하는 H2에 포함됩니다.
- 저장하면 **바뀐 섹션만** 몇 초 안에 다시 색인됩니다. 방금 저장한 내용이 바로 안 나오면 잠시 뒤 다시 찾아보세요.
- 그래서 H2 섹션을 주제별로 잘 나눈 문서일수록 잘 찾힙니다.
- 휴지통의 문서, 보관된 Space의 문서는 나오지 않습니다.

## 에이전트의 검색

에이전트는 MCP 도구 `search_pages`(단어)와 `semantic_search`(뜻)를 씁니다. `semantic_search`는 섹션 id를 알려 주므로, 에이전트가 문서 전체 대신 그 섹션만 읽습니다. [[MCP 도구 레퍼런스]] 참고.
