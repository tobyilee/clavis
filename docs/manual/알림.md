내 문서의 댓글, 나를 부르는 멘션, 지켜보는 문서의 변경을 알려 주는 기능입니다. 상위 문서: [[Clavis 사용 매뉴얼]]

## 알림 벨

- 헤더의 🔔에 **안 읽은 알림 수**가 뜹니다 (1분마다 갱신).
- 누르면 최근 알림 목록이 열립니다. 항목마다 페이지 제목, 누가(🧑/🤖), 무엇을, 언제.
- 항목을 누르면 읽음 처리되고 해당 위치로 갑니다.
  - **문서 수정** → 변경 기록의 차이 화면 (마지막으로 읽은 뒤 바뀐 범위 전체)
  - **새 댓글·멘션** → 페이지의 댓글
- **모두 읽음**으로 한 번에 정리합니다.

## 알림이 오는 경우

| 종류 | 언제 |
|---|---|
| 새 댓글 | 내가 만들었거나, 담당(`owner`)이거나, 댓글을 단 문서, 또는 지켜보는 문서에 새 댓글·답글 |
| 나를 언급 | 누가 댓글에서 나를 `@멘션` |
| 문서 수정 | 지켜보는 문서가 바뀜 |

- 내가 한 일은 나에게 알리지 않습니다.
- 휴지통에 간 문서의 알림은 목록에서 숨겨집니다.

## 한 건으로 묶기

같은 문서의 같은 종류 알림은 **읽기 전까지 한 건**으로 묶입니다. 에이전트가 한 문서를 연달아 다섯 번 고쳐도 알림은 하나이고 "Adam · 문서 수정 5번"처럼 보입니다. 읽고 나면 다음 변경부터 새 알림이 됩니다.

## 지켜보기

- 다음 문서는 **자동으로** 지켜봅니다: 내가 만든 문서, 내가 담당(`owner` — 이메일 또는 이름)인 문서, 내가 댓글을 단 문서.
- 그 밖의 문서는 페이지 메뉴(⋯) → **지켜보기**.
- 같은 메뉴에서 지켜보는 이유(예: "담당 문서라 알림을 받는 중")를 보고, **알림 끄기**로 그 문서의 알림을 끕니다. **알림 다시 받기**로 되돌립니다.

## 에이전트 수정 알림 끄기

에이전트가 자주 고치는 문서라 알림이 많다면, 알림 목록 맨 아래의 **에이전트의 문서 수정은 알리지 않기**를 켭니다. 사람이 고친 것과 댓글·멘션은 계속 옵니다.

## 에이전트와 알림

- 에이전트는 **멘션만** 알림으로 받습니다 (문서 수정·새 댓글 알림은 사람에게만).
- 에이전트는 MCP `list_notifications`로 멘션을 확인하고, 처리한 뒤 `mark_notifications_read`로 읽음 처리합니다. [[댓글과 멘션]] 참고.

## 보관 기간

읽은 알림은 30일 뒤 지워집니다.
