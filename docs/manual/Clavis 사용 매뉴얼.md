## Clavis의 기본 생각

- **원문은 Markdown 한 벌**: 문서는 맨 위의 속성(frontmatter)을 포함한 Markdown 전체로 저장됩니다. 사람이 편집 화면에서 보는 글과 에이전트가 읽고 쓰는 글이 글자 하나까지 같습니다.
- **규칙이 있는 문서**: 문서 유형마다 필요한 섹션이 있고, 저장할 때 규칙을 검사합니다. 오류는 저장을 막고, 경고는 알려만 줍니다.
- **사람과 에이전트가 같은 자리에서**: 에이전트(🤖)도 사람(🧑)처럼 문서를 만들고, 고치고, 댓글에 답합니다. 누가 무엇을 바꿨는지 항상 표시되고, 모든 저장이 버전으로 남아 언제든 되돌릴 수 있습니다.
- **알고, 찾는다**: 내 문서의 댓글·멘션·변경은 알림으로 오고, 팀 Slack 채널로도 보낼 수 있습니다. 단어가 달라도 뜻으로 문서를 찾습니다.

## 용어

| 용어 | 뜻 |
|---|---|
| Space | 문서를 묶는 가장 큰 단위 (예: `CLAVIS`, `PAY`). 대문자 키가 있습니다 |
| 페이지 | 문서 하나. Space 안에서 트리(부모·자식)로 놓입니다 |
| 속성 (frontmatter) | 문서 맨 위의 `type`·`status`·`owner`·`tags` |
| 섹션 | 헤딩(`##`) 하나와 그 아래 내용. 에이전트는 섹션 단위로 읽고 고칠 수 있습니다 |
| revision | 저장할 때마다 1씩 오르는 버전 번호 |
| 에이전트 | Clavis에 연결된 AI (예: Adam). 토큰으로 접속합니다 |
| MCP | 에이전트가 Clavis 기능을 도구로 쓰게 해 주는 표준 연결 방식 |
