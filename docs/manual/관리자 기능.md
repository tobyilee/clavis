관리자만 쓰는 화면입니다. 헤더(또는 사이드바 아래)의 **관리**를 누르면 탭 네 개가 나옵니다. 상위 문서: [[Clavis 사용 매뉴얼]]

## 사람

- Clavis에 로그인한 사람 목록입니다. 새로 로그인한 사람은 **승인 대기**로 맨 위에 보입니다.
- **역할** 선택으로 승인하고 권한을 정합니다: 승인 대기 · 뷰어 · 편집자 · 관리자. 역할별로 할 수 있는 일은 [[시작하기]].
- **사용 중지**하면 로그인해도 쓸 수 없습니다. **다시 사용**으로 되돌립니다.
- 내 계정은 바꿀 수 없습니다 ("나"로 표시).

## AI 에이전트

에이전트는 사람 대신 **토큰**으로 접속하는 계정입니다. 문서에는 🤖와 이름으로 표시됩니다.

1. **에이전트 이름**과 **역할**(편집자·뷰어)을 정하고 **에이전트 추가**. 같은 이름을 막지 않으므로 먼저 목록에서 중복을 확인합니다. `minsu-claude`처럼 주인과 도구가 드러나고 공백 없는 이름을 권합니다.
2. 에이전트 행의 **토큰 발급** → 대화상자에 토큰(`clv_…`)이 **한 번만** 보입니다. **복사**해서 에이전트 설정에 넣습니다. 다시 볼 수 없으니 잃어버리면 새로 발급합니다.
3. 사용자가 요청한 에이전트라면 **서비스 토큰**(Cloudflare Access)도 준비해 값 세 개(Client ID, Client Secret, `clv_…`)를 기록이 남지 않는 방법으로 전달합니다. 사람별 서비스 토큰을 만드는 법과 전달 방법은 [[내 AI 에이전트 등록하고 연결하기]]의 2단계, 연결 방법은 [[AI 에이전트 연결 (MCP)]].

- 연필 버튼으로 **이름 변경**. 문서·댓글·변경 기록의 작성자 표시가 새 이름으로 바뀌고, 목록에서 골라 넣은 `@멘션`은 이름이 바뀌어도 같은 에이전트에게 갑니다.
- 토큰 목록에서 앞 8자, **마지막 사용** 시각을 보고, 필요 없으면 **폐기**합니다. 에이전트마다, 도구마다 토큰을 따로 발급하면 누가 무엇을 했는지와 호출 한도가 분리됩니다.
- **사용 중지**하면 그 에이전트는 어떤 토큰으로도 접속할 수 없습니다 (403 `disabled`). 작성 기록은 남고, **다시 사용**으로 되돌립니다.
- 에이전트는 1분에 120번까지 호출할 수 있습니다(사람은 600번). 넘으면 잠시 기다려야 합니다.

## Space

- **새 Space**: 키(대문자로 시작하는 2~10자, 나중에 바꿀 수 없음), 이름, 설명. 만들면 홈 페이지가 함께 생깁니다.
- **편집**: 이름·설명 변경.
- **보관**: 더 쓰지 않는 Space를 보관합니다. 읽을 수는 있지만 고칠 수 없고, 검색에서 빠집니다. **보관 해제**로 되돌립니다.

## 의미 검색

[[검색]]의 **뜻으로 찾기**를 위한 색인 상태입니다.

- **색인된 문서**: 현재 버전으로 색인된 문서 수 / 전체 문서 수
- **벡터 (무료 한도)**: 사용 중인 벡터 수 / 4,882. 문서의 H2 섹션 하나가 벡터 하나쯤입니다. **80%를 넘으면 경고**가 뜨니, 유료 플랜 전환을 검토합니다.
- **색인 만들기**: 색인이 안 됐거나 오래된 문서만 골라 색인합니다. 진행률이 표시되고, 몇 초~몇 분 걸립니다.
- 평소에는 저장할 때마다 자동으로 색인되므로 누를 일이 거의 없습니다. 하루 무료 사용량을 넘어 색인이 밀린 문서는 매일 밤 자동으로 다시 시도합니다.

## 무료 플랜에서 알아 둘 것

Clavis는 Cloudflare 무료 플랜에서 돌아갑니다. 한도를 넘으면 요금이 나가는 대신 **그 기능이 잠시 실패**합니다.

| 항목 | 무료 한도 | 넘으면 |
|---|---|---|
| 요청 | 하루 10만 번 | 그날 남은 시간 동안 접속 실패 |
| 의미 검색 색인 (Workers AI) | 하루 약 900만 토큰 | 그날 색인·의미 검색 실패 → 글자 검색으로 대체, 다음 날 이어서 색인 |
| 벡터 저장 (Vectorize) | 4,882개 | 새 섹션 색인 실패 |
| 저장 공간 | DB 500MB, 파일 10GB | 저장 실패 |
