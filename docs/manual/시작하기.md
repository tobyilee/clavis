Clavis에 처음 들어와서 화면을 익히는 방법입니다. 상위 문서: [[Clavis 사용 매뉴얼]]

## 로그인과 권한

1. Clavis 주소(`https://clavis.crawl-proxy.workers.dev`)를 엽니다.
2. Cloudflare Access 로그인 화면에서 이메일을 입력하고, 메일로 받은 PIN을 넣습니다.
3. 처음 로그인하면 **승인 대기** 화면이 나옵니다. 관리자가 역할을 정해 주면 문서를 볼 수 있습니다.

| 역할 | 할 수 있는 일 |
|---|---|
| 뷰어 (viewer) | 문서 읽기, 검색, 댓글·답글 달기, 즐겨찾기, 알림 받기 |
| 편집자 (editor) | 뷰어 + 페이지 만들기·고치기·이동·삭제, 복원, 댓글 해결, 템플릿 관리 |
| 관리자 (admin) | 편집자 + 사람·에이전트·토큰·Space 관리, Space 문서 규칙, 알림 채널, 의미 검색 색인 |

- 맨 처음 로그인한 사람이 관리자가 됩니다.
- 에이전트는 편집자나 뷰어만 될 수 있습니다.

## 화면 구성

| 위치 | 내용 |
|---|---|
| 헤더 왼쪽 | **Clavis** 로고 — 누르면 홈 |
| 헤더 검색 칸 | 제목·본문 검색. **⌘K**(Windows는 Ctrl+K)로 어디서든 열립니다 |
| **KO / EN** | 화면 언어 바꾸기 |
| 🔔 | 알림 (안 읽은 수 표시). [[알림]] 참고 |
| **관리** | 관리자에게만 보입니다. [[관리자 기능]] 참고 |
| 왼쪽 사이드바 | Space 선택, 페이지 트리, 새 페이지, 문서 상태, Space 설정, 휴지통 |
| 본문 | 페이지 내용. 넓은 화면에서는 오른쪽에 목차(TOC) |

휴대폰에서는 사이드바가 왼쪽에서 열리는 서랍이 되고, 목차는 본문 위에 접혀 있습니다.

## 홈

로고를 누르면 나오는 홈에는 다음이 모입니다.

- **Space** 목록 (관리자는 여기서 새 Space를 만들 수 있음)
- **즐겨찾기**: 페이지의 ☆를 누른 문서
- **최근 본 문서**: 휴대폰과 PC에서 같이 보이며, 최근 50개
- **최근 변경**: 전체 · 사람 · 에이전트로 거를 수 있습니다
- **내 문서의 열린 댓글**: 내가 만들었거나 담당(`owner`)인 문서의 해결되지 않은 댓글

## 페이지 보기

- 페이지 제목 아래에 유형·상태·담당·태그가 보입니다.
- 오른쪽 목차(TOC)의 헤딩을 누르면 그 위치로 이동합니다. 헤딩 옆 숫자 배지는 그 섹션에 달린 열린 댓글 수입니다.
- 페이지 아래쪽: **이 페이지를 링크하는 문서**(백링크), **댓글**.
- 페이지 메뉴(⋯)
  - **편집**, **하위 페이지 추가**, **이동**, **삭제**
  - **변경 기록** — [[변경 기록과 되돌리기]]
  - **지켜보기 / 알림 끄기** — [[알림]]
  - **AI용 복사 (Markdown)**: 제목·URL·원문을 한 번에 복사합니다. ChatGPT·Claude 같은 AI 채팅에 붙여 넣어 질문할 때 씁니다.
  - **원본 Markdown 열기 (.md)**: 속성을 포함한 원문을 새 탭에서 엽니다. 페이지 주소 끝에 `.md`를 붙여도 같습니다.
- ☆ 버튼으로 즐겨찾기에 넣고 뺍니다.

## 페이지 주소

- 페이지 주소는 `/s/<Space 키>/p/<제목>-<짧은 id>` 모양입니다. 제목이 바뀌어도 짧은 id가 같으면 같은 페이지로 갑니다.
- 섹션으로 바로 가는 주소는 끝에 `#섹션-id`를 붙입니다 (예: `…#액션-아이템`).
