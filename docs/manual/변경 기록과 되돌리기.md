누가 언제 무엇을 바꿨는지 보고, 이전 버전으로 되돌리는 방법입니다. 상위 문서: [[Clavis 사용 매뉴얼]]

## 모든 저장이 버전으로 남는다

- 편집 화면의 저장뿐 아니라 섹션 편집(에이전트), 속성 변경, 제목 변경으로 자동 수정된 링크, 복원까지 **모든 저장**이 버전 하나가 됩니다.
- 버전은 지워지지 않습니다. 페이지를 휴지통에서 영구 삭제할 때만 함께 지워집니다.
- 변경 기록 기능이 생기기 전에 만든 문서는, 그 뒤 첫 저장 때 이전 본문을 "기록 시작 전 내용"으로 남기고 거기서부터 기록합니다.

## 변경 기록 보기

페이지 메뉴(⋯) → **변경 기록**을 엽니다.

- **버전 목록**: 버전 번호(r1, r2 …), 누가(🧑 사람 / 🤖 에이전트), 언제, 크기 변화, 종류

| 종류 | 뜻 |
|---|---|
| 만듦 | 페이지를 처음 만든 버전 |
| 수정 | 일반 저장 |
| 링크 자동 수정 | 다른 페이지의 제목이 바뀌어 `[[링크]]`가 고쳐짐 |
| rN에서 복원 | rN 버전의 본문을 되살린 저장 |
| 기록 시작 전 내용 | 변경 기록 기능 이전의 본문 |

- 버전을 고르면 **바뀐 내용**에 바로 이전 버전과의 차이가 줄 단위로 보입니다. 같은 줄은 "N줄 같음"으로 접힙니다.
- **비교 대상**을 바꾸면 임의의 두 버전을 비교할 수 있습니다.
- 알림에서 "문서 수정"을 누르면, 내가 마지막으로 본 뒤 바뀐 전체 범위의 차이가 바로 열립니다.

## 되돌리기 (복원)

1. 되돌리고 싶은 버전을 고릅니다.
2. **이 버전으로 복원** → 확인.

- 복원은 그 버전의 본문을 **새 버전으로 저장**합니다. 지금 본문도 기록에 남으므로 복원한 것도 다시 되돌릴 수 있습니다.
- 제목은 바뀌지 않습니다 (본문만 되돌림).
- 그사이 다른 사람이 저장했으면 목록을 새로 고친 뒤 다시 시도합니다.
- 그사이 Space의 문서 규칙이 바뀌어 옛 본문이 오류에 걸리면 복원되지 않습니다. 이때는 옛 버전을 보고 편집 화면에서 직접 고칩니다.

## 에이전트가 크게 고쳤을 때

1. 알림의 "문서 수정"을 눌러 차이를 봅니다 (또는 변경 기록에서 🤖 버전 선택).
2. 괜찮으면 그대로 두고, 아니면 에이전트 이전 버전으로 복원합니다.
3. 원하는 방향을 댓글로 `@에이전트`에게 다시 요청합니다.

에이전트도 MCP로 변경 기록을 읽고(`list_revisions`, `read_revision`) 스스로 되돌릴 수 있습니다(`restore_revision`). [[MCP 도구 레퍼런스]] 참고.
