새 페이지를 만들고, 편집 화면에서 쓰고, 저장하는 방법입니다. 상위 문서: [[Clavis 사용 매뉴얼]]

## 새 페이지 만들기

1. 사이드바의 **새 페이지**, 트리 항목의 **+**, 또는 페이지 메뉴(⋯)의 **하위 페이지 추가**를 누릅니다.
2. **제목**을 적고 **템플릿**을 고릅니다. 템플릿에는 그 문서 유형에 필요한 섹션이 미리 들어 있습니다.
3. **만들고 편집하기**를 누르면 편집 화면이 열립니다.

제목은 Space 안에서 겹칠 수 없습니다. 제목이 곧 페이지의 H1이므로 본문에 `# 제목`을 다시 쓰지 않습니다.

### 기본 템플릿과 필수 섹션

| 템플릿 (`type`) | 필수 섹션 (H2) |
|---|---|
| PRD (`prd`) | 배경, 목표, 사용자 스토리, 요구사항, 범위 외 |
| 기술 명세 (`spec`) | 개요, 요구사항, 설계, 미결 사항 |
| ADR (`adr`) | Context, Decision, Consequences |
| 아키텍처 (`architecture`) | 개요, 구성 요소, 데이터 흐름 |
| 회의록 (`meeting`) | 참석자, 논의 내용, 결정 사항, 액션 아이템 |
| 가이드 (`guide`), 노트 (`note`) | 없음 |

- 섹션 이름은 한국어와 영어 모두 인정합니다 (`## 개요` 또는 `## Overview`). 뒤에 말을 붙여도 됩니다 (`## 설계 (v2)`).
- Space에 **커스텀 템플릿**이 있으면 기본 템플릿보다 먼저 나옵니다. Space가 필수 섹션을 바꿨다면 기본 템플릿도 그 목록으로 채워집니다. [[Space 설정]] 참고.

## 편집 화면

- **왼쪽**은 Markdown 에디터, **오른쪽**은 미리보기입니다. 한쪽을 스크롤하면 다른 쪽이 따라옵니다.
- **속성**(유형·상태·담당·태그)은 위쪽 폼에서 바꾸거나, 에디터 맨 위의 YAML을 직접 고칩니다. 둘은 같은 내용입니다.

```yaml
---
type: spec          # prd | spec | adr | architecture | meeting | guide | note
status: draft       # draft(초안) | review(검토 중) | approved(승인됨) | deprecated(폐기됨)
owner: toby@example.com
tags: [결제, api]
---
```

- **⌘S**(Windows는 Ctrl+S)는 저장하고 계속 편집합니다. **저장** 버튼은 저장한 뒤 보기 화면으로 돌아갑니다.
- **문제** 패널에 규칙 위반이 줄 번호와 함께 보입니다. 누르면 그 줄로 갑니다. 자세한 규칙은 [[Markdown 문법과 문서 규칙]].
- 필수 섹션이 빠졌으면 속성 폼 아래의 **끝에 추가**로 한 번에 넣을 수 있습니다.
- `[[`를 입력하면 페이지 제목 목록이 떠서 위키 링크를 고를 수 있습니다. `[[KEY:`는 다른 Space의 페이지입니다.

### 이미지와 파일 첨부

- 에디터에 **붙여넣기**, **끌어다 놓기**, 또는 📎 버튼으로 파일을 고릅니다. 업로드가 끝나면 본문에 참조가 자동으로 들어갑니다.

```markdown
![구조도](attachments/구조도.png)
[명세서 원본](attachments/spec.pdf)
```

- 파일당 25MB까지. 같은 이름이 있으면 `-1`이 붙습니다.

### 초안과 충돌

- 저장하지 않고 창을 닫아도 **초안**이 이 브라우저에 남습니다. 다시 열면 복구할지 묻습니다.
- 편집하는 동안 다른 사람(또는 에이전트)이 먼저 저장했다면 저장할 때 알려 줍니다. **내 내용 복사하고 최신본 불러오기**를 누른 뒤 내 변경을 다시 적용합니다. 남의 저장을 덮어쓸 수는 없습니다.
- 잘못 저장했더라도 모든 저장이 버전으로 남으므로 [[변경 기록과 되돌리기]]에서 되돌릴 수 있습니다.

## 휴대폰에서 편집하기

- 편집 화면이 화면 전체를 덮고, 키보드가 뜨면 키보드 위 영역에 맞춰집니다. 제목과 **저장**은 항상 위에 있습니다.
- [편집 | 미리보기] 탭으로 바꿔 봅니다.
- 키보드 바로 위 **서식 툴바**: 헤딩(누를 때마다 `##` → `###` → 해제), 굵게, 목록, 체크박스, 링크, 위키 링크(`[[`), 코드. 글자를 선택하고 누르면 감싸고, 다시 누르면 풀립니다.
- **사진 첨부**(툴바의 카메라 버튼): 카메라로 찍거나 사진 보관함에서 고릅니다. 큰 사진은 올리기 전에 긴 변 2000px JPEG로 줄입니다 (아이폰 HEIC도 JPEG로 바뀜).
- **속성**과 문제 수 배지(예: **문제 2개**)는 아래에서 올라오는 시트로 열립니다.

## 제목 바꾸기

- 편집 화면에서 제목을 바꿔 저장하면, 다른 문서의 `[[옛 제목]]` 링크가 자동으로 `[[새 제목]]`으로 바뀝니다 (별칭 유지, 코드 블록 안은 그대로).
- 고쳐진 문서에는 제목을 바꾼 사람이 수정자로 남고, 변경 기록에 "링크 자동 수정"으로 기록됩니다.
- 링크하는 문서가 아주 많으면(50개 또는 합계 200KB 초과) 일부는 고쳐지지 않고, 몇 개가 남았는지 알려 줍니다. 바꾸기 전에 페이지 아래 **이 페이지를 링크하는 문서**를 확인하세요.
