# 문서 작성 가이드

> Clavis에서 페이지를 만들고 고치는 방법, 쓸 수 있는 Markdown 문법, 저장할 때 검사하는 규칙, 댓글·문서 상태·Space 설정·홈 화면, 변경 기록·알림·의미 검색을 정리한다.
> 에이전트 연결은 [agent-connection.md](./agent-connection.md)를 본다.

## 1. 페이지 만들기

1. 사이드바의 **새 페이지**, 트리 항목의 **+**, 또는 페이지 메뉴(⋯)의 **하위 페이지 추가**를 누른다.
2. 제목을 적고 **템플릿**을 고른다. 템플릿에는 그 문서 유형에 필요한 섹션이 미리 들어 있다.
3. **만들고 편집하기**를 누르면 편집 화면이 열린다.

| 템플릿 (`type`) | 필수 섹션 (H2) |
|---|---|
| PRD (`prd`) | 배경, 목표, 사용자 스토리, 요구사항, 범위 외 |
| 기술 명세 (`spec`) | 개요, 요구사항, 설계, 미결 사항 |
| ADR (`adr`) | Context, Decision, Consequences |
| 아키텍처 (`architecture`) | 개요, 구성 요소, 데이터 흐름 |
| 회의록 (`meeting`) | 참석자, 논의 내용, 결정 사항, 액션 아이템 |
| 가이드 (`guide`), 노트 (`note`) | 없음 |

섹션 이름은 한국어와 영어 모두 인정한다 (예: `## 개요` 또는 `## Overview`). 뒤에 말을 덧붙여도 된다 (`## 설계 (v2)`).

Space에 **커스텀 템플릿**이 있으면 기본 템플릿보다 먼저 나온다(§8). Space 설정에서 필수 섹션을 바꿨다면 기본 템플릿도 그 목록으로 채워진다.

## 2. 편집 화면

- **왼쪽** Markdown 에디터, **오른쪽** 미리보기. 한쪽을 스크롤하면 다른 쪽이 따라온다. 휴대폰에서는 [편집 | 미리보기] 탭으로 바꾼다.
- **속성**(유형·상태·담당·태그)은 위쪽 폼에서 바꾸거나 에디터 맨 위 YAML을 직접 고친다. 둘은 같은 내용이다.
- **⌘S**(Windows는 Ctrl+S)로 저장하고 계속 편집한다. **저장** 버튼은 저장 후 보기 화면으로 돌아간다.
- **이미지·파일**: 에디터에 붙여넣거나 끌어다 놓거나 📎 버튼으로 고른다. 업로드가 끝나면 참조가 자동으로 들어간다.
- 저장하지 않고 창을 닫아도 **초안**이 이 브라우저에 남는다. 다시 열면 복구할지 묻는다.
- **휴대폰**: 편집 화면이 화면 전체를 덮고, 키보드가 뜨면 키보드 위 영역에 맞춰진다. 제목과 **저장**은 항상 위에 있다.
  - 키보드 바로 위 **서식** 툴바: 헤딩(누를 때마다 ## → ### → 해제), 굵게, 목록, 체크박스, 링크, 위키 링크(`[[`), 코드. 글자를 선택하고 누르면 감싸고, 다시 누르면 풀린다.
  - **사진 첨부**(툴바의 카메라 버튼): 카메라로 찍거나 사진 보관함에서 고른다. 큰 사진은 올리기 전에 긴 변 2000px JPEG로 줄인다(아이폰 HEIC도 JPEG로 바뀜).
  - **속성**과 문제 수 배지(예: **문제 2개**)는 아래에서 올라오는 시트로 열린다. 문제를 누르면 그 줄로 간다.
- 편집하는 동안 다른 사람(또는 에이전트)이 먼저 저장했다면 저장할 때 알려 준다. **내 내용 복사하고 최신본 불러오기**를 누른 뒤 내 변경을 다시 적용한다. 덮어쓰기는 할 수 없다. 대신 모든 저장이 버전으로 남으므로, 잘못 고쳐졌으면 변경 기록에서 되돌린다(§10).

## 3. Markdown 문법

기본은 CommonMark + GFM(표, 체크리스트, 취소선, 각주, 자동 링크)이다. HTML 태그와 수식은 쓰지 않는다.

| 문법 | 예 | 설명 |
|---|---|---|
| 위키 링크 | `[[환불 정책]]` | 같은 Space의 페이지. 없는 페이지면 빨간 점선으로 보인다 |
| 표시 텍스트 | `[[환불 정책\|정책 문서]]` | 링크 글자를 바꾼다 |
| 다른 Space | `[[ARCH:공통 원칙]]` | Space 키를 앞에 붙인다 |
| 첨부 | `![구조도](attachments/구조도.png)` | 이 페이지에 올린 파일 |
| Callout | `> [!NOTE]` 다음 줄부터 `> 내용` | NOTE, TIP, IMPORTANT, WARNING, CAUTION |
| 코드 | ` ```ts ` … ` ``` ` | 언어를 적어야 색이 입혀진다 |
| 다이어그램 | ` ```mermaid ` … ` ``` ` | Mermaid 문법 |

- 페이지 제목이 곧 H1이다. 본문은 `##`(H2)부터 쓴다.
- 에디터에서 `[[`를 입력하면 페이지 제목을 고를 수 있다.
- 페이지 **제목을 바꾸면** 다른 문서의 `[[옛 제목]]` 링크가 자동으로 `[[새 제목]]`으로 바뀐다(별칭 유지, 코드 블록 안은 그대로). 고쳐진 문서에는 제목을 바꾼 사람이 수정자로 남는다. 링크하는 문서가 아주 많으면(50개 또는 합계 200KB 초과) 일부는 고쳐지지 않고, 저장할 때 몇 개가 남았는지 알려 준다.

## 4. 문서 규칙 (Lint)

편집하는 동안 에디터에 밑줄과 **문제** 패널로 보인다. 같은 규칙을 저장할 때 서버가 다시 검사한다.

| 심각도 | 저장 | 규칙 |
|---|---|---|
| **오류** | 막힘 | frontmatter가 없거나 YAML이 틀림 · `type`·`status`·`owner`가 없거나 허용되지 않는 값 · 없는 첨부 파일 참조 |
| **경고** | 됨 | 본문 H1 · 헤딩 레벨 건너뜀(H2 → H4) · 없는 페이지로의 위키 링크 · 유형별 필수 섹션 누락 |
| **정보** | 됨 | 이미지 alt 없음 · 코드 블록 언어 없음 · 50KB 넘는 문서(나누기 권장) · 서식(markdownlint, 편집 화면에서만) |

- 필수 섹션이 빠졌으면 속성 폼 아래의 **끝에 추가**로 한 번에 넣을 수 있다.
- 본문은 100KB까지 저장된다. 그보다 크면 하위 페이지로 나눈다.
- 위 표는 기본값이다. Space마다 규칙의 수준·필수 섹션·긴 문서 기준을 바꿀 수 있다(§8).

## 5. 정리하기

- **이동**: 사이드바에서 페이지를 끌어 다른 페이지 위(앞)·가운데(하위로)·아래(뒤)에 놓는다. 휴대폰이나 키보드에서는 페이지 메뉴 → **이동**.
- **삭제**: 페이지 메뉴 → **삭제**. 하위 페이지와 함께 **휴지통**으로 가고, 30일 안에 복원할 수 있다. Space 홈 페이지는 지울 수 없다.
- **검색**: 헤더의 검색 칸 또는 **⌘K**. 3글자 이상은 색인으로, 더 짧으면 부분 일치로 찾는다. 띄어쓰기가 다르면 찾지 못한다(`부분 환불` ≠ `부분환불`). 단어가 달라도 뜻으로 찾으려면 검색 화면의 **뜻으로 찾기**를 켠다(§12).

## 6. 댓글

- 페이지 보기 맨 아래 **댓글**에 의견이나 질문을 남긴다. 본문은 Markdown이고(위키 링크 가능), ⌘Enter로 등록한다.
- **섹션**을 고르면 그 헤딩에 연결된다. 헤딩 옆에 열린 댓글 수 배지가 붙고, 누르면 해당 스레드로 이동한다.
- 스레드에는 **답글**을 한 단계로 단다. 논의가 끝나면 **해결** — 해결된 스레드는 접혀서 **해결된 스레드 N개 보기**로 다시 볼 수 있고, **다시 열기**도 된다.
- 권한: 댓글·답글은 읽을 수 있는 사람 누구나(viewer 포함), 수정은 쓴 사람, 삭제는 쓴 사람과 관리자, 해결은 editor 이상. 답글이 달린 첫 댓글은 지울 수 없으니 해결로 닫는다.
- 에이전트(🤖)도 댓글을 읽고 답글을 달고 해결한다. 예: "이 섹션에 환불 정책을 넣어 주세요"라고 남기면, 에이전트가 문서를 고친 뒤 답글을 달고 해결한다.
- 새 댓글과 답글은 **알림**으로 온다(§11). 홈의 **내 문서의 열린 댓글**에도 내가 담당(`owner`)하거나 만든 문서의 열린 스레드가 모인다.
- **@멘션**: 댓글에 `@`를 치면 사람·에이전트 목록이 뜬다. 고르면 그 사람(또는 에이전트)에게 알림이 간다. 예: "@Adam 이 섹션 정리해 줘" → Adam이 알림을 읽고 고친 뒤 답글을 단다.

## 7. 문서 상태 (대시보드)

- 사이드바의 **문서 상태**: 이 Space의 규칙 위반과 깨진 링크를 한눈에 본다.
  - 요약: 전체 페이지, 문제 있는 페이지, 오류·경고 수, 깨진 링크 수.
  - **규칙별**·**페이지별** 목록. 위반을 누르면 편집 화면이 열리고 그 줄로 이동한다.
  - **깨진 링크**: 없는 페이지를 가리키는 `[[위키 링크]]`. 지금 상태 그대로라, 대상 페이지를 만들면 바로 사라진다.
- 규칙 결과는 **저장할 때** 기록된다. 규칙 설정이 바뀌었거나 아직 기록이 없는 페이지는 이 화면을 열면 자동으로 다시 검사한다(“현재 규칙으로 다시 검사하는 중… N/M”). 검사 전 결과에는 “(이전 규칙 기준)”이 붙는다.
- 페이지 보기 아래에는 **이 페이지를 링크하는 문서**(백링크)가 나온다. 제목을 바꾸거나 지우기 전에 확인한다.

## 8. Space 설정 (문서 규칙·템플릿·알림 채널)

사이드바의 **Space 설정**. 누구나 볼 수 있고, 규칙과 알림 채널은 관리자만, 템플릿은 editor 이상이 바꾼다.

- **문서 규칙** — 편집기, 저장, 에이전트 API에 똑같이 적용된다.
  - **규칙별 수준**: 끔 · 정보 · 경고 · 오류(저장 차단). frontmatter 규칙은 오류로 고정이다.
  - 규칙을 **오류로 올리면** 그 규칙을 어기는 문서의 저장이 그때부터 막힌다. 이미 저장된 문서는 그대로 남고, 다음에 저장할 때 고쳐야 한다. 문서 상태 화면에서 어떤 문서가 걸리는지 확인한다.
  - **유형별 필수 섹션**: 체크하면 이 Space만의 목록을 쓴다. 한 줄에 섹션 하나, `결정 | Decision`처럼 쓰면 두 이름 모두 인정한다.
  - **긴 문서 기준**: 이 크기를 넘으면 나누기를 권하는 정보가 뜬다(기본 50KB).
- **템플릿** — 새 페이지를 만들 때 고를 수 있는 팀 템플릿.
  - **새 템플릿** → 이름·설명·문서 유형·내용. **기본 템플릿에서 시작…**으로 기본 템플릿을 불러와 고칠 수 있다.
  - `{{title}}`은 페이지 제목, `{{owner}}`는 만든 사람, `{{date}}`는 만든 날짜로 바뀐다. frontmatter에 `owner: {{owner}}`를 그대로 두면 된다.
  - 템플릿도 이 Space 규칙으로 검사하며, 오류가 있으면 저장되지 않는다. 템플릿을 지워도 이미 만든 페이지는 그대로다.
  - 관리자는 **모든 Space에서 쓰기**로 전체 공용 템플릿을 만들 수 있다.
- **알림 채널** (관리자) — 이 Space의 소식을 Slack 채널이나 다른 시스템으로 보낸다.
  - **Slack**: Slack에서 채널의 Incoming Webhook을 만들고, **채널 추가**에 받은 URL(`https://hooks.slack.com/services/…`)을 붙여 넣는다. URL은 비밀이므로 채팅 등에 붙이지 말고 이 화면에만 넣는다. 저장 뒤에는 끝 네 글자만 보인다.
  - **JSON Webhook**: https 주소로 서명된 JSON을 보낸다(받는 방법은 [agent-connection.md](./agent-connection.md) §8).
  - **보낼 소식**: 새 문서, 문서 수정, 휴지통 이동, 복원, 새 댓글, 댓글 해결. 같은 사람이 같은 문서를 5분 안에 여러 번 고치면 Slack에는 한 번만 간다.
  - **테스트 전송**으로 연결을 바로 확인한다. 카드 아래에 최근 전달 기록(✓/✗, 재시도 횟수, 오류)이 보인다. 실패하면 30초·2분·10분 뒤에 다시 보낸다.

## 9. 홈과 즐겨찾기

- 로고를 누르면 나오는 **홈**: Space 목록, **즐겨찾기**, **최근 본 문서**(휴대폰과 PC에서 같음, 최근 50개), **최근 변경**(전체 · 사람 · 에이전트로 거르기), **내 문서의 열린 댓글**.
- 페이지 위쪽 메뉴(⋯) 옆의 ☆를 누르면 즐겨찾기에 들어가고, 사이드바 위쪽에도 보인다.
- 페이지 메뉴(⋯)
  - **AI용 복사 (Markdown)**: 제목·URL·원문을 한 번에 복사한다. ChatGPT·Claude 같은 AI 채팅에 붙여 넣어 질문할 때 쓴다.
  - **원본 Markdown 열기 (.md)**: frontmatter를 포함한 원문을 새 탭에서 연다. 페이지 URL 끝에 `.md`를 붙여도 같다.

## 10. 변경 기록과 되돌리기

- 모든 저장(섹션 편집, 속성 변경, 제목 변경으로 고쳐진 링크, 복원 포함)이 **버전**으로 남는다. 버전은 지워지지 않고, 페이지를 휴지통에서 영구 삭제할 때만 함께 지워진다.
- 페이지 메뉴(⋯) → **변경 기록**: 버전마다 번호, 누가(🧑 사람 / 🤖 에이전트), 언제, 크기 변화, 종류(만듦·수정·링크 자동 수정·복원).
- 버전을 고르면 **바뀐 내용**에 바로 이전 버전과의 차이가 줄 단위로 보인다(같은 줄은 "N줄 같음"으로 접힘). **비교 대상**을 다른 버전으로 바꿀 수 있다.
- **이 버전으로 복원**: 그 버전의 본문을 **새 버전으로 저장**한다. 지금 본문도 기록에 남으므로 복원도 다시 되돌릴 수 있다. 제목은 바뀌지 않는다. 그 사이 문서 규칙이 바뀌어 옛 본문이 오류에 걸리면 복원되지 않으니 편집 화면에서 직접 고친다.
- 변경 기록 기능 이전에 만든 문서는 그 뒤 첫 저장부터 기록이 시작된다(첫 저장 때 이전 본문을 "기록 시작 전 내용"으로 남긴다).

## 11. 알림

- 헤더의 🔔에 안 읽은 알림 수가 뜬다. 누르면 목록이 열리고, 항목을 누르면 해당 위치로 간다(문서 수정은 변경 기록의 차이 화면, 댓글·멘션은 페이지 댓글). **모두 읽음**으로 한 번에 정리한다.
- 알림이 오는 경우:
  - 내가 만들었거나 담당(`owner`)이거나 댓글을 단 문서의 **새 댓글·답글**
  - 누가 나를 **@멘션**
  - **지켜보는** 문서가 바뀜 — 내가 만든·담당·댓글 단 문서는 자동으로 지켜보고, 다른 문서는 페이지 메뉴의 **지켜보기**로 추가한다. 그 메뉴에서 지켜보는 이유(예: "담당 문서라 알림을 받는 중")를 보고 **알림 끄기**·**알림 다시 받기**도 할 수 있다.
- 같은 문서의 같은 종류 알림은 읽기 전까지 **한 건으로 묶인다**("Adam · 문서 수정 5번").
- 에이전트가 고친 것까지 알림을 받고 싶지 않다면 알림 목록 맨 아래의 **에이전트의 문서 수정은 알리지 않기**를 켠다.
- 읽은 알림은 30일 뒤 지워진다. Space의 Slack 채널로도 받으려면 §8 **알림 채널**.

## 12. 뜻으로 찾기 (의미 검색)

- 검색 화면에서 **뜻으로 찾기**를 켜면, 단어가 달라도 뜻이 비슷한 내용을 함께 찾는다(예: "환불 기준" → "부분 취소 정책"). 단어 검색 결과와 합쳐서 순서를 매긴다.
- 결과에는 가장 가까운 **섹션**이 "› 섹션 이름"으로 붙고, 누르면 그 섹션으로 바로 간다.
- 문서는 H2 섹션 단위로 색인되고, 저장하면 바뀐 섹션만 몇 초 안에 다시 색인된다.
- 결과는 한 페이지(최대 20개)만 나온다. 일시적으로 쓸 수 없으면 "글자로 찾은 결과입니다"라는 안내와 함께 단어 검색 결과가 나온다.
- 관리자: **관리 → 의미 검색**에서 색인된 문서 수와 벡터 사용량(무료 한도 4,882개)을 보고, 색인이 안 된 문서가 있으면 **색인 만들기**를 누른다.

## 13. 내 표시 이름

- 헤더 오른쪽 끝의 내 이름(폰에서는 사람 아이콘)을 누르고 **표시 이름 바꾸기**. 처음 이름은 로그인할 때의 이름이나 이메일 앞부분이다.
- 문서 작성자, 변경 기록, 댓글, 알림, Slack 메시지 등 내가 나오는 모든 곳에 보이고, **지난 기록에도 새 이름**이 보인다.
- 1~64자. `[`·`]`·줄바꿈은 쓸 수 없고, 다른 사람이나 에이전트가 쓰는 이름(대소문자 무시)도 쓸 수 없다.
- 공백 없는 이름이면 댓글에서 `@이름`으로 불린다. 자동 완성(`@` 입력)은 공백이 있어도 된다. 이미 쓴 댓글의 멘션도 새 이름으로 보인다.
- 문서 담당(`owner`)에 이름 대신 **이메일**을 쓰면, 이름을 바꿔도 그 문서의 알림을 계속 받는다.
- 폰에서는 언어(한국어·English)도 이 메뉴에서 고른다.
- 관리자는 **관리 → 일반**에서 사이트 제목을 정한다. 모든 사람의 화면 왼쪽 위와 브라우저 탭에 `Clavis - 제목`으로 보인다.
