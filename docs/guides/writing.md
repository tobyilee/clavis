# 문서 작성 가이드

> Clavis에서 페이지를 만들고 고치는 방법, 쓸 수 있는 Markdown 문법, 저장할 때 검사하는 규칙을 정리한다.
> 에이전트 연결은 [agent-connection.md](./agent-connection.md)를 본다.

## 1. 페이지 만들기

1. 사이드바의 **새 페이지**, 트리 항목의 **+**, 또는 페이지 메뉴(⋯)의 **하위 페이지 추가**를 누른다.
2. 제목을 적고 **템플릿**을 고른다. 템플릿에는 그 문서 유형에 필요한 섹션이 미리 들어 있다.
3. **만들고 편집하기**를 누르면 편집 화면이 열린다.

| 템플릿 (`type`) | 필수 섹션 (H2) |
|---|---|
| PRD (`prd`) | 배경, 목표, 사용자 스토리, 요구사항, 범위 외 |
| 기술 명세 (`spec`) | 개요, 요구사항, 설계, 미결 사항 |
| ADR (`adr`) | Context, Decision, Consequences |
| 아키텍처 (`architecture`) | 개요, 구성 요소, 데이터 흐름 |
| 회의록 (`meeting`) | 참석자, 논의 내용, 결정 사항, 액션 아이템 |
| 가이드 (`guide`), 노트 (`note`) | 없음 |

섹션 이름은 한국어와 영어 모두 인정한다 (예: `## 개요` 또는 `## Overview`). 뒤에 말을 덧붙여도 된다 (`## 설계 (v2)`).

## 2. 편집 화면

- **왼쪽** Markdown 에디터, **오른쪽** 미리보기. 한쪽을 스크롤하면 다른 쪽이 따라온다. 휴대폰에서는 [편집 | 미리보기] 탭으로 바꾼다.
- **속성**(유형·상태·담당·태그)은 위쪽 폼에서 바꾸거나 에디터 맨 위 YAML을 직접 고친다. 둘은 같은 내용이다.
- **⌘S**(Windows는 Ctrl+S)로 저장하고 계속 편집한다. **저장** 버튼은 저장 후 보기 화면으로 돌아간다.
- **이미지·파일**: 에디터에 붙여넣거나 끌어다 놓거나 📎 버튼으로 고른다. 업로드가 끝나면 참조가 자동으로 들어간다.
- 저장하지 않고 창을 닫아도 **초안**이 이 브라우저에 남는다. 다시 열면 복구할지 묻는다.
- 편집하는 동안 다른 사람(또는 에이전트)이 먼저 저장했다면 저장할 때 알려 준다. **내 내용 복사하고 최신본 불러오기**를 누른 뒤 내 변경을 다시 적용한다. 버전 기록이 없으므로 덮어쓰기는 할 수 없다.

## 3. Markdown 문법

기본은 CommonMark + GFM(표, 체크리스트, 취소선, 각주, 자동 링크)이다. HTML 태그와 수식은 쓰지 않는다.

| 문법 | 예 | 설명 |
|---|---|---|
| 위키 링크 | `[[환불 정책]]` | 같은 Space의 페이지. 없는 페이지면 빨간 점선으로 보인다 |
| 표시 텍스트 | `[[환불 정책\|정책 문서]]` | 링크 글자를 바꾼다 |
| 다른 Space | `[[ARCH:공통 원칙]]` | Space 키를 앞에 붙인다 |
| 첨부 | `![구조도](attachments/구조도.png)` | 이 페이지에 올린 파일 |
| Callout | `> [!NOTE]` 다음 줄부터 `> 내용` | NOTE, TIP, IMPORTANT, WARNING, CAUTION |
| 코드 | ` ```ts ` … ` ``` ` | 언어를 적어야 색이 입혀진다 |
| 다이어그램 | ` ```mermaid ` … ` ``` ` | Mermaid 문법 |

- 페이지 제목이 곧 H1이다. 본문은 `##`(H2)부터 쓴다.
- 에디터에서 `[[`를 입력하면 페이지 제목을 고를 수 있다.
- 페이지 **제목을 바꾸면** 옛 제목으로 된 위키 링크는 자동으로 고쳐지지 않는다. 저장할 때 몇 개가 깨졌는지 알려 준다.

## 4. 문서 규칙 (Lint)

편집하는 동안 에디터에 밑줄과 **문제** 패널로 보인다. 같은 규칙을 저장할 때 서버가 다시 검사한다.

| 심각도 | 저장 | 규칙 |
|---|---|---|
| **오류** | 막힘 | frontmatter가 없거나 YAML이 틀림 · `type`·`status`·`owner`가 없거나 허용되지 않는 값 · 없는 첨부 파일 참조 |
| **경고** | 됨 | 본문 H1 · 헤딩 레벨 건너뜀(H2 → H4) · 없는 페이지로의 위키 링크 · 유형별 필수 섹션 누락 |
| **정보** | 됨 | 이미지 alt 없음 · 코드 블록 언어 없음 · 50KB 넘는 문서(나누기 권장) · 서식(markdownlint, 편집 화면에서만) |

- 필수 섹션이 빠졌으면 속성 폼 아래의 **끝에 추가**로 한 번에 넣을 수 있다.
- 본문은 100KB까지 저장된다. 그보다 크면 하위 페이지로 나눈다.

## 5. 정리하기

- **이동**: 사이드바에서 페이지를 끌어 다른 페이지 위(앞)·가운데(하위로)·아래(뒤)에 놓는다. 휴대폰이나 키보드에서는 페이지 메뉴 → **이동**.
- **삭제**: 페이지 메뉴 → **삭제**. 하위 페이지와 함께 **휴지통**으로 가고, 30일 안에 복원할 수 있다. Space 홈 페이지는 지울 수 없다.
- **검색**: 헤더의 검색 칸 또는 **⌘K**. 3글자 이상은 색인으로, 더 짧으면 부분 일치로 찾는다. 띄어쓰기가 다르면 찾지 못한다(`부분 환불` ≠ `부분환불`).
